# Support

## Questions and bug reports

Open an issue on GitHub: <https://github.com/stateforge-labs/harness-kit/issues>. Pick the bug report or feature request form, which
asks for the details we need: the package and version, the harness and its version, the steps to reproduce, and what you expected.

Before you open an issue, check the [README](README.md), the [package READMEs](packages/hooks/README.md), and the
[architecture page](docs/architecture.md). The hook server's environment variables and exit codes are in the
[server README](packages/hooks-server/README.md).

Remove private data from anything you paste: prompts, tokens, file paths that name you or your machine, and email addresses.

## Security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).

## Response times

Issues are read by maintainers on a best-effort basis. There is no response time guarantee for support.
